# 💖 Bil ♥ Napi - Sổ Kỷ Niệm Tình Yêu

Website lưu trữ kỷ niệm, album hình ảnh, đếm ngày yêu và những mốc thời gian đáng nhớ của **Bil & Napi**.

## 🚀 Hướng Dẫn Xem & Đưa Lên Web (Deployment)

### Cách 1: Đưa lên Vercel (Khuyên dùng - Nhanh nhất 30s)
1. Truy cập [vercel.com](https://vercel.com) và đăng nhập bằng tài khoản GitHub.
2. Bấm **"Add New Project"** -> Chọn Repo **`bil-napi`**.
3. Bấm **"Deploy"**. Bạn sẽ có ngay đường link web trực tiếp để xem và chia sẻ!

### Cách 2: Sử dụng GitHub Pages
1. Vào Repo của bạn trên GitHub (`github.com/Tên_Tài_Khoản/bil-napi`).
2. Vào **Settings** > **Pages**.
3. Mục **Build and deployment** -> **Source**: Chọn **GitHub Actions**.
4. Website sẽ tự động build và chạy tại địa chỉ `https://<tên-tài-khoản>.github.io/bil-napi/`.
